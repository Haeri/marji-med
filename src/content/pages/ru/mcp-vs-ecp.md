## Главное различие

Наружная контрпульсация (ECP) сдавливает ноги снаружи с помощью пневматических манжет. Мышечная контрпульсация (MCP) сдавливает периферические сосуды изнутри, вызывая сокращение мышц ног.

![Два поперечных сечения ноги. При ECP наружная манжета давит на конечность снаружи внутрь. При MCP сама мышца сокращается вокруг центрального сосуда.](/uploads/compression-diagram.svg)

*Поперечное сечение конечности, схема. При ECP манжета (тёмная) давит снаружи внутрь. При MCP стимулируемая мышца (красная) сокращается вокруг сосудов. Стимуляция осуществляется через электроды на коже (тёмные полоски).*

## Сравнение

| | MCP | ECP |
| --- | --- | --- |
| Источник компрессии | Мышцы голеней и бёдер пациента | Пневматические манжеты на ногах |
| Мышцы во время лечения | Активны | Пассивны |
| Преднагрузка | Нежелательного повышения можно избежать, по словам изобретателя метода | Сопоставимых утверждений нет |
| Средство воздействия | Самоклеящиеся кожные электроды | Манжеты, наполняемые от компрессора |
| Триггер | ЭКГ | ЭКГ |
| Момент воздействия | С каждым сердечным сокращением стимулируется одна из четырёх зон, в раннюю диастолу | Последовательное наполнение манжет в диастолу снизу вверх начиная с голеней, сброс давления перед систолой |
| Оборудование | Портативный генератор импульсов с батарейным питанием | Стационарная лечебная установка |
| Курс | 30 минут ежедневно в течение восьми дней в опубликованных исследованиях | Обычно 35 сеансов по одному часу |
| Сосудистый доступ | Нет | Нет |
| Доказательная база | Небольшие исследования, в основном в послеоперационном периоде и при сердечной недостаточности | Более длительный клинический опыт, в основном при рефрактерной стенокардии |

## MCP, физические нагрузки и EMS

MCP также часто путают с физическими тренировками и электромиостимуляцией (EMS). Изобретатель метода описывает различие следующим образом.

| | Мышцы | Суставы | Сердце |
| --- | --- | --- | --- |
| Физическая нагрузка | Нагружаются | Нагружаются | Нагружается |
| EMS | Щадящая нагрузка, отдельные группы | Не затрагиваются | Нагружается |
| MCP | Щадящая нагрузка, отдельные группы | Не затрагиваются | Разгружается |

## Как читать это сравнение

Мы не нашли исследований, в которых MCP и ECP сравнивались бы напрямую, поэтому таблица лишь описывает методы и не должна рассматриваться как свидетельство большей эффективности одного из них.

Каждый метод необходимо оценивать применительно к конкретному показанию. Например, в кокрейновском обзоре не найдено убедительных данных в пользу рутинного применения ECP при остром ишемическом инсульте. Наиболее близкое опубликованное сравнение для MCP — исследование на животных с внутриаортальной баллонной контрпульсацией: у шести телят MCP и баллонная контрпульсация оказывали одинаковое влияние на сердечный выброс и ударную работу левого желудочка, при этом MCP также снижала общее периферическое сосудистое сопротивление.
