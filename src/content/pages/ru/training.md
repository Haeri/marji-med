## Лечение в Тбилиси

Медицинский центр сердца и кровообращения «Марджи» приглашает пациентов с сердечно-сосудистыми заболеваниями на неинвазивное лечение методом MCP наряду с другими методами. Процедуры проводятся под руководством изобретателя метода.

Центр имеет лицензии Министерства здравоохранения Грузии на амбулаторную помощь взрослым (№ 000248) и детям (№ 000249), выданные в 2005 году.

## Семинары для врачей

Изобретатель метода проводит семинары по MCP для врачей в рамках аккредитации Министерства здравоохранения Грузии № PS-152 «Современные методы лечения сердечно-сосудистой патологии».

| | |
| --- | --- |
| Продолжительность | Три дня |
| Содержание | Теория (философия метода) и практика |
| Сертификат | Выдаётся по окончании семинара |
| Размер группы | До четырёх участников |
| Стоимость | 4000 евро за группу, без учёта проезда и проживания |
| Место проведения | Медицинский центр «Марджи» или, по договорённости, горный или морской курорт |
